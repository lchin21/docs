---
title: "Changing Variables"
---

To change the config, such as the color scheme, without rerunning the script, set the config variables and call the load function.

```javascript
window.theAnimeCommunityConfig = {
    MAL_ID: 'EXAMPLE',
    episodeChapterNumber: 'EXAMPLE',
    mediaType: 'EXAMPLE'
};

window.theAnimeCommunity.reload()
```
